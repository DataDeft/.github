# Datadeft

**Applied AI & Cloud Economics**

We build software for complex data and practical decisions, from financial
documents and scientific datasets to cloud workloads.

## What we're working on

- **Applied AI:** extracting structured information from documents and building
  applications around it.
- **Scientific data platforms:** connecting experimental data, metadata and model
  outputs for analysis and AI training.
- **Cloud economics:** modelling workload demand, comparing infrastructure options
  and planning cost improvements.

## Products in development

- [CeleraTax](https://www.celeratax.eu/): AI-assisted reconciliation of invoices
  and bank statements for Hungarian small businesses.
- [Panzerotti](https://www.panzerotti.be/): e-commerce intelligence that connects
  performance, SEO and AI search visibility to practical improvements.

## Open source

[datadeft-auth](https://github.com/DataDeft/datadeft-auth) is our Rust library
collection for proof-of-work, encrypted session tokens and scanner-safe magic-link
login, with optional Axum and AWS adapters. It is under active development and
remains pre-1.0.

## How we build

Our stack includes Rust, Python, TypeScript, Astro, Restate, AWS and Terraform.
We work across the application, its data and its infrastructure, with tested
code, repeatable deployments and clear ownership.

Based in Hungary, working across the EU.
